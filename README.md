# Обробка та аналіз супутникових знімків класичними методами

STEM-проєкт з дисципліни «Комп'ютерна графіка та візуалізація».
Виконала: Потапова Надія, ІПЗ-23.

> Проєкт у розробці. Повна інструкція з'явиться після реалізації пайплайнів.

## Встановлення

```bash
pip install -r requirements.txt
```

```bash
python -m satimg config      # показати конфігурацію

```
