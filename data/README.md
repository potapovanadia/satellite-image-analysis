# Вибірка зображень

**Джерело:** UC Merced Land Use Dataset — Yang, Y., & Newsam, S. (2010).
*Bag-of-visual-words and spatial extensions for land-use classification.*
ACM SIGSPATIAL GIS 2010. Аерофотознімки USGS National Map, 256×256 пікселів,
RGB, роздільна здатність ≈ 0,3 м/піксель, 21 клас по 100 зображень.

**Робоча вибірка проєкту:** 100 зображень — 5 класів по 20 знімків.

| Клас | Що на знімках | Файли |
|---|---|---|
| `agricultural` | поля, рілля з регулярними рядками | `agricultural00`–`19` |
| `forest` | лісові масиви, однорідна зерниста текстура | `forest00`–`19` |
| `river` | річки, береги, рослинність | `river00`–`19` |
| `freeway` | автомагістралі з розміткою та узбіччями | `freeway00`–`19` |
| `denseresidential` | щільна житлова забудова | `denseresidential00`–`19` |

**Правило відбору:** з кожного класу взято перші 20 файлів за номером (00–19).
Відбір детермінований, тому вибірку можна точно відтворити з оригінального архіву.

Перевірка вибірки та створення опису `data/manifest.csv`:

```bash
python -m satimg dataset
```
